# Scripts historiques

Les scripts autonomes sont classés par domaine sous ce répertoire. Ils sont conservés pour référence, mais sont distincts de l'application maintenue sous `src/`.

La CI les vérifie uniquement avec `bash -n` : aucune VM, aucun conteneur et aucune ressource Proxmox ne sont créés par les tests. Consultez [les précautions](../docs/legacy/README.md) avant toute maintenance.
